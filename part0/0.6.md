    participant browser
    participant server

    Note right of browser: User enters a note and clicks Save
    Note right of browser: JavaScript prevents the default form submission (e.preventDefault())

    Note right of browser: JavaScript creates a new note object with content and date
    Note right of browser: The new note is added to the local notes array

    Note right of browser: JavaScript calls redrawNotes() to update the page

    browser->>server: POST https://studies.cs.helsinki.fi/exampleapp/new_note_spa
    activate server
    Note right of server: Server saves the new note
    server-->>browser: HTTP 201 Created
    deactivate server

    Note right of browser: Browser receives the server response
